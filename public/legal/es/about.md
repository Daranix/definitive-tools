# Acerca de Definitive Tools

Le damos la bienvenida a **Definitive Tools**, una colección de código abierto de utilidades para desarrolladores diseñada para que las tareas diarias de programación y formateo sean más rápidas, sencillas y totalmente seguras.

## La filosofía de la privacidad ante todo

Muchas herramientas online para desarrolladores requieren subir datos a un servidor remoto. Cuando formatea JSON, genera un código QR o inspecciona un token JWT en sitios convencionales, su contenido, potencialmente sensible, se transmite por la web.

Definitive Tools se ha construido de forma diferente:
- **Procesamiento 100 % en el cliente:** todos los cálculos, el formateo, el análisis y las conversiones se ejecutan directamente dentro del entorno aislado de su navegador web.
- **Cero ingesta en servidores:** sus datos nunca abandonan su equipo. No disponemos de servidores de backend que almacenen o registren sus entradas.

## Código abierto y auditable

El código fuente de Definitive Tools es completamente abierto y está alojado en [GitHub](https://github.com/Daranix/definitive-tools). Cualquier persona puede inspeccionar la implementación, verificar las declaraciones de seguridad, crear un fork del repositorio o contribuir con mejoras.

## Funciones principales

- **Integración con Monaco Editor:** un completo envoltorio de edición de código con resaltado de sintaxis y formateo automático.
- **Generador Swagger/OpenAPI:** renderizado del diseño de la API en el cliente y generación de código SDK para cliente y servidor.
- **Herramientas Markdown:** convertidores en vivo para exportar contenido Markdown a HTML, hojas de cálculo de Excel o documentos PDF.
- **Suite de utilidades esenciales:** herramientas de alta calidad para la generación de códigos QR, la eliminación del fondo de imágenes, la conversión a y desde Base64, el análisis de JWT y la creación de contraseñas aleatorias.
